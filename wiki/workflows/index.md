# Munkafolyamatok

Hogyan csinálunk dolgokat — fejlesztés, deploy, telepítés. Valódi parancsokkal, nem elvi
leírással.

Akkor írj ide, ha egy munkafolyamat, parancs vagy script bekerült, átnevezésre került vagy
megszűnt. Ha egy hibahelyzet elhárításáról van szó, az a [runbooks/](/runbooks/index.md)-ba megy.

* [Fejlesztői környezet](fejlesztoi-kornyezet.md) - repo, futtatás, portok, a proxy amiért nincs CORS
* [Deploy](deploy.md) - git push → Coolify build → élesedés, és mit kell egyszer beállítani
* [Telepítés iPhone-ra](telepites-iphone-ra.md) - kezdőképernyőre tétel mindkét telefonra, lépésről lépésre
